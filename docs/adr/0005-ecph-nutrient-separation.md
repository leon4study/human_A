# 5. EC/pH는 nutrient 도메인으로 분리, 필터 막힘은 룰 기반

Date: 2026-04-23

## Status

Accepted

## Context

초기에는 EC/pH 같은 화학 지표를 주력 신호로 보려 했으나, 두 가지 문제가 드러났다.

- EC/pH는 양액 조성·보정에 따라 정상 변동이 크고, 물리적 막힘과의 직접 상관이 약하다.
  물리 지표(유량·압력·전류·진동)가 막힘 진행을 더 직접적으로 반영한다.
- 필터 막힘 신호(필터 차압)는 학습 데이터에 실제 막힘 사례가 없고, 단일 변수 상관이 약하다
  (r=0.37 수준의 독립 신호).

## Decision

- 물리 지표를 주력으로 삼고, EC/pH·염류 축적 등 화학 지표는 별도 `nutrient` 도메인으로 분리한다.
  `nutrient`는 오탐이 잦아 전체 통합 알람 투표에서 제외한다(개별 도메인 알람으로는 유지).
- 필터 막힘은 별도 AE를 두지 않고 프론트엔드의 **룰 기반 페이지**로 운영한다.

## Consequences

- 통합 알람의 신뢰도가 올라간다(오탐 잦은 nutrient를 투표에서 뺌).
- "EC/pH를 제외했다"는 식의 서술은 정확하지 않다. 제외가 아니라 별도 도메인으로 분리해
  보조 지표로 운영하는 것이다. 포트폴리오·문서 표현은 이 구분을 지킨다.
- 필터 페이지는 학습 모델이 아니라 규칙으로 동작하므로, 모델 성능 지표에 포함하지 않는다.
